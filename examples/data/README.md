# Example Data

The sample workflow references:

- `examples/data/sample_R1.fastq.gz`
- `examples/data/sample_R2.fastq.gz`

These files do not need to exist for mock-mode runs. Mock mode is the default so the demo can run on a clean machine without FastQC, fastp, or MultiQC installed.

For real execution, replace those paths with real FASTQ or FASTQ.GZ files and turn off mock mode in the UI or request payload.
