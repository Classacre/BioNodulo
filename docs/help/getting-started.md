# Getting Started With BioNodulo

BioNodulo is a node-based workspace for building, running, and reviewing bioinformatics workflows.

## First Steps

1. Open or create a workflow.
2. Add input nodes for files such as FASTQ, FASTA, VCF, BAM, CSV, or directories.
3. Connect analysis, quality-control, visualization, and reporting nodes.
4. Run the workflow and review generated reports, previews, logs, and runtime artifacts.

## Practical Workflow Checks

- Validate input files early with Data Validator nodes.
- Use QC and reporting nodes to summarize read counts, alignment metrics, variants, coverage, and plots.
- Save reusable workflows as templates when the graph is stable.
