# Postmortems

Blameless write-ups of production incidents and near-misses in the execution
engine: what happened, what the blast radius was, what contributed, and what
changed as a result.

Format: `YYYY-MM-DD-short-slug.md`. Record incidents that reveal a gap the
tests or design did not cover — not routine failures. Reference the relevant
decision record in `docs/decisions/` when a postmortem leads to one.
