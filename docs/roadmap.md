# Roadmap

Near-term:

- Stronger node validation hooks
- Better frontend file pickers
- Per-node force rerun from the UI
- More built-in nodes for common teaching workflows
- Tool version capture
- More complete output browsing

Later:

- Conda environment creation
- Docker and Apptainer execution
- Snakemake export
- Nextflow export
- CWL/WDL export
- Reusable workflow templates
- Optional checksums for selected large inputs
- Public community node index

Out of scope for the MVP:

- Cloud execution
- User accounts
- Authentication
- Database-backed collaboration
- Full workflow DSL design
