# 0.1.1-alpha.3

Imported workflows, duplicated tabs and new cloud drafts now share one durable
creation lifecycle. A stable request UUID prevents duplicate rows after an
ambiguous response. Edits made during creation are retained and then saved in
order. Account/team-scoped recovery, visible failure states and retry protection
reduce the chance of losing a draft during reload or signing into another account.
Cloud writes check the captured account/team before mutation. Native provenance,
annotations and references survive save/restore; metadata-only edits trigger saves.

Workflow conversion now checks graph and native-language contracts before
claiming an export succeeded. See the [portability guide](../workflow-portability.md)
for verified workflows and limits. Unchanged native exports can recover the
original ports, options, layout and references; edited marked sources are refused
instead of restoring stale metadata. A CWL download is explicitly a bundle of
workflow and tool documents, with a separate round-trip manifest.
Exporters read the editor's actual parameter schema. Native execution checks cover
spaces in filenames, literal punctuation in options, and non-default FastQC flags.

The website records authenticated upload provenance, verifies reserved size/type
before completion, and offers **Finish upload** after a verification failure or
reload. Members can delete their own recorded uploads; old objects without
provenance remain admin/owner deletion only.

Scoped dependency updates remove the remaining known production advisories.
Direct Solana HTTP client and Metro image-parser compatibility checks now run in
CI, alongside a production dependency audit. Lazy workspace stores consistently
use the running app's configured root.

Safe hot workspace switching still requires a restart. Arbitrary foreign
workflow languages, every scientific node and PhD completeness are not certified
by this release. Native engine execution, browser journeys, cloud image pins and
desktop asset publication are verified separately in release receipts.
