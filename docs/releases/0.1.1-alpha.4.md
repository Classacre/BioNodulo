# 0.1.1-alpha.4

Nextflow and Snakemake exports now preserve MultiQC's **Overwrite** setting.
Previously, both generated commands always enabled `--force`, even when the
node had it disabled. A missing or false option now omits the flag; true adds it,
and a non-boolean value returns an export error.

MultiQC writes into a temporary directory before collecting its report and data
outputs. This keeps its intermediate filenames separate from staged inputs.
Nextflow stages both tools' inputs in a separate directory. Real-engine checks
covered input basenames that collide with report/data output names and verified
that source file and directory checksums stayed unchanged.

The website's Files page now signs downloads with an attachment disposition and
a safe UTF-8 filename. Text files download instead of opening a preview tab.

Malformed foreign CWL objects, ports and source/output references return client
errors instead of server errors or incomplete graphs. Valid foreign bundles
still import as structural drafts with a review warning.

Import error notices now appear above the Import dialog, keep keyboard focus,
and can be dismissed before retrying. At narrow widths the header wraps instead
of shifting the entire editor off screen after a modal closes. Browser checks
cover all four advertised export downloads and unchanged reimports, metadata
preservation, error dismissal, and header/menu access at 508 and 1280 pixels.

See the [workflow portability guide](../workflow-portability.md) for the supported
FastQC/MultiQC graph, five executable CWL transforms, and structural Galaxy
interchange. Foreign imports remain structural drafts; this patch does not
expand the executable tool or language coverage.
