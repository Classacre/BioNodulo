# 0.1.1-alpha.8

Focusing and leaving canvas fields no longer changes saved workflow parameters.
Untouched fields preserve omitted defaults, including connected inputs. String
fields declared multiline now use text areas, preserving line breaks and trailing
newlines during display and editing. These shared widget fixes apply to the
desktop editor, cloud editor, and embedded MCP workbench.

The MCP workbench retains validation and run review state for unchanged canvas
callbacks. Actual edits still mark the draft unsaved and require saving and
reviewing before a run. Regression tests cover keyboard navigation, multiline
edits, omitted parameters, JSON validation, numeric and color edits, and external
value updates. Production browser tests exercise the real canvas through the MCP
host protocol without submitting paid runs.

This patch provides new desktop installers; published alpha.7 binaries are
unchanged.

Installers now build into a draft release. One publisher verifies all signed
updater payloads and publishes the complete platform manifest after all builds
finish, then makes the release public. This prevents concurrent platform builds
from overwriting updater metadata or exposing an incomplete release.
