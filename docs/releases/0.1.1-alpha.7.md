# 0.1.1-alpha.7

Saved and imported connections to scalar inputs now render their input handles
and wires in the desktop editor, cloud editor, and embedded MCP workbench. For
example, a String node connected to Write File's content input no longer appears
disconnected when the workflow has no saved widget-promotion flags. Browser
regressions verify the actual SVG edge and its port endpoints.

The embedded workbench's Host assistant Send button and Enter key now work in
hosts whose iframe sandbox does not permit native forms. Tests cover input Enter,
keyboard activation of Send, and clicking Send, including the MCP context and
message requests.

The locked worker environment now includes Pydantic, which semantic validation
requires before executing workflows. The coordinated cloud worker update runs
relative outputs inside the run directory so Write File can create its output
and include it in the artifact upload manifest. The worker image build also
checks a real String-to-Write File workflow in its locked runtime; these cloud
runner changes are maintained in the website repository.

This release provides new desktop installers for the shared canvas correction;
already published alpha.6 installers are unchanged.
