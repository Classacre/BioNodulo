# Decision records

Short, numbered records of engineering decisions that shape the execution
engine. Each file captures context, what was adopted, and what was explicitly
rejected with the reason — so future work does not re-litigate settled calls
or silently undo a trade-off.

Naming: `NNNN-short-slug.md`, sequential, never reused.
